# Networking Demos

This section contains demonstrations of Kubernetes networking features.

## Topics Covered

- Network policies for pod-to-pod communication
- Service types (ClusterIP, NodePort, LoadBalancer)
- Ingress controllers and routing rules
- DNS and service discovery
- CNI plugins and configurations

## Demos

- `network-policy-demo.yaml` - Network policies for pod-to-pod communication control
- `ingress-routing-demo.yaml` - Host and path-based HTTP routing with Ingress

## Common Use Cases

- Isolating workloads with network policies
- Exposing applications internally and externally
- Load balancing traffic across pods
- Service mesh integration
- Cross-namespace communication
